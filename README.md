#  QurbaniHat - Livestock Booking Platform

<img src="https://i.ibb.co.com/xS2Yt7r4/Behance-Mockup-Shot-Cover-3.png" alt="DocAppoint Preview" width="700" />

**QurbaniHat** is a modern web application designed to digitalize the process of viewing and booking sacrificial animals for Qurbani. It provides a seamless interface for users to browse livestock and manage their bookings.

Live Site: https://qurbanihat-livestock-booking-platfo.vercel.app

## Features

*   **Responsive UI:** Fully optimized for Mobile, Tablet, and Desktop screens.
*   **Secure Authentication:** User Login and Registration (Register/Login) powered by Better-Auth.
*   **Animal Listings:** A dedicated section to browse all available animals with details.
*   **User Profiles:** Personalized profile pages for users to manage their information.
*   **Real-time Feedback:** Integrated `react-hot-toast` for instant success or error notifications (e.g., during login or logout).
*   **Modern Navigation:** Active link highlighting to help users know which page they are currently on.

## 🛠 Tech Stack

*   **Framework:** Next.js (App Router)
*   **Styling:** Tailwind CSS
*   **UI Components:** HeroUI
*   **Authentication:** Better-Auth
*   **Database:** MongoDB
*   **Language:** JavaScript
